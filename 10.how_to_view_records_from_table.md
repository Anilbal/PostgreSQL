# how to view records from table

```
SELECT * FROM table_name;
```

## results

```
anilbal=> SELECT * FROM person;
 id | first_name | last_name | gender | created_at
----+------------+-----------+--------+------------
  1 | Anil       | Bal       | Male   |
  2 | Sanjay     | lama      | Male   |
  3 | Angel      | Guffadhi  | Female |
(3 rows)

```

## SELECT * FROM table_name;

It is a SQL query used to retrieve all records and all columns from a table in PostgreSQL.

## SELECT first_name FROM table_name;

This retrieves only the first_name column from the person table in PostgreSQL.

## View multiple column from table

```
anilbal=> SELECT column_name, column_name From person;

example:
anilbal=> SELECT first_name, last_name From person;
```
