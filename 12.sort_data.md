# how to sort data in postgres

By default sorting is done in ascending order.

## how to sort table data in ascending order

```
SELECT * FROM table_name ORDER BY type_name;
```

It means retrieve all records from a table and sort them in ascending order based on the type_name column.

### Example of sorting in ascending order

```
SELECT * FROM person ORDER BY last_name;
```

NOTE: default is by ascending order so you dont need to type SELECT * FROM person ORDER BY last_name ASC;
