# Offset in postgres

In PostgreSQL, OFFSET is used to skip a specific number of rows before returning the results.

```
SELECT * FROM table_name OFFSET number;
```

# Combine Offset with Limit

Combining offset with limit to give specific records.

```
SELECT * FROM table_name OFFSET number LIMIT number;
```
