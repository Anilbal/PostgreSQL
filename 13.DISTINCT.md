## DISTINCT in posgres

DISTINCT is used to remove duplicate values from the query result. It returns only unique records.

```
SELECT DISTINCT table_column FROM table_name;
```

## example

```
anilbal=> SELECT DISTINCT gender FROM person;
   gender
-------------
 Genderqueer
 Bigender
 Genderfluid
 Male
 Non-binary
 Polygender
 Female
 Agender
(8 rows)

```
